Speaker settings & calibration notes

The KRK is the fixed acoustic source. Record actual controls before formal runs; do not rerun ARC between positions. Software does not change speaker settings or apply correction.

Optional EMM-6 speaker reference

Optionally record the KRK response and a reference playback level once using the Dayton Audio EMM-6. Save the recording and calibration file for later synthetic-versus-real comparison. Main Play & record uses XVF MIC0–MIC3 and never requires the EMM-6. Correction and deconvolution are deferred.

Absolute sensitivity (advanced, optional)

Enter a positive value only if established for this microphone and interface gain. A frequency-response calibration file does not establish absolute sensitivity.

Optional archive only: keep the original EMM-6 recording, calibration file and fixed KRK settings for later analysis. No speaker correction or deconvolution is required now or applied automatically.
