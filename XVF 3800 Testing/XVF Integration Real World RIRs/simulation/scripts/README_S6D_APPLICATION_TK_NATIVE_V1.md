# Owned native/Tk causal-view harness (prospective)

Purpose: eight proposed source-paced mono-input jobs on accepted GUIv3 source, using C065 anonymous/C088 originalA15 repairedT0. One native engine and its actual gallery score calls feed a single controlled dispatcher. C088 has concurrent independent T0/T1/T2 presentation states and actual owned Tk windows. No extra decoder, model, gallery query or source reset is created for a selected view. This is an opt-in experiment harness, not a changed default. Root has authorized implementation and model-free checks only; **no native/Tk/model/device launch has occurred or is authorized by this README**.

Inputs: exact manifest/source/support/helper/asset/profile/gallery/WAV bindings; expected source and identity frames/PCM hash; fixed selected opaque A15 IDs; root-admitted1..4 logical CPU affinity IDs; fresh output directory and supervisor protocol. The native helper enforces50GiB free on C and75GiB on G; the outer supervisor must additionally enforce the shared40GiB campaign payload cap. It never opens a live audio input/output stream. Only the owned worker's Tk windows are created when an eventual reviewed job is launched; no unrelated application/desktop/window is accessed.

s6d_application_tk_native_v1.py exposes run_one(manifest_path, job_id, checkpoint=None), compatible with the existing in-process native protocol wrapper. Every declared source and support file must remain immutable. The actual native engine imports only the frozen GUIv3 source. Both streams use the same admitted mono waveform, fixed weights/endpoint/profile and fresh decoder state. Checkpoint calls before/after startup and in the live consumer pump allow the existing supervisor STOP protocol. Interactive start/enrollment is disabled; an owned-window close requests stop and cannot succeed as a full-input result.

The harness deliberately replaces only its own native inbox with a bounded8192-event CausalInbox that preserves every native partial and final without coalescing. This ensures a complete online causal event stream for comparison; overflow is an explicit failure. It adds load relative to ordinary partial-coalescing application behavior, so timing is specific to this declared instrumentation. Frozen application source stays unchanged. View inboxes use the frozen bounded EventInbox and record consumed plus permissible obsolete-partial coalescing. All raw native events and all committed displays remain journaled; every view receives identical event-order hashes. A separate frozen PresentationState T0 is compared against actual native T0 output by text/identity/visibility/source-span semantics; clocks are compared as distinct stages, not expected equal.

The real isolated ResearchGallery.score executes once per actual native query. A bounded observation spy records vector digest, unchanged returned candidates/scores and call start/finish clocks; it does not tune thresholds or call the gallery from a selected view. The spy is restored after the owned session. Complete unfiltered words are preserved while a T1/T2 view may hide pending/unselected/unknown spans. Selection is prebound from the original gallery, never from audio, scorer references, seats or an active-speaker oracle.

Outputs: RESULT.json only after full semantic validation, full consumer_events.jsonl, resources.jsonl and progress.json, source/session journals/transcripts, per-view s6d_gui_render.jsonl with actual callback/widget-command clocks/text hash, actual_gallery_queries.json and event-order/drain proofs. Clocks share perf_counter and the actual source_started origin; record native publication, dispatcher admission, presentation and Tk update separately. These are actual Tk commands/callbacks, not physical display scanout, phonetic latency or device/CM5 proof. Three concurrent views add UI load; their timing does not characterize a single-view product. Eight probes establish wiring only; retained focus configurations still require the full17+4 paced coverage under suitable consumer instrumentation.

The root-accepted s6d_native_evidence_v1.py supplies the final completion and full-dispatch guard: actual PCM journals must match exact source frames/hash, source/ASR/speaker consumption must complete, scheduler watermarks/queues and finalizers must close, and every GUI view/observer/consumer must drain. A headless completion cannot claim GUI evidence. The source/owner/protocol graph and external process exit remain separate supervisor duties. Failed prefixes, STOP, overflow, source mismatch, GUI callback error or missing evidence are not COMPLETE. No missing reference correctness is invented; the separately reviewed offline scorer must assess source-bound lexical/name correctness after a real run.

Model-free checks below import only stdlib harness logic, frozen PresentationState and event contracts. They create no Tk root, load no neural model and access no audio device. They test selected/unknown/demotion visibility with full words preserved, T0 equivalence, causal order/digest tamper, queue saturation, incomplete-view closure and original gallery-score delegation. All test output is fresh on G. These checks are not GUI execution qualification. The initial fixture suffix is reserved; repeat deliberately only into a new suffix.
