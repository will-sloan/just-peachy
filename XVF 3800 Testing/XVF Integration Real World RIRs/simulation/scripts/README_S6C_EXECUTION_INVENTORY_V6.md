Purpose: append the separately reviewed C085 O0-ASR/O1-ID and C086 O1-ASR/O0-ID single-scene paced schema to held inventory V5. Original V4/V5, canonical/sentinel coordinators, frozen APP and native workers remain unchanged. V6 does not construct or launch jobs. It privately compiles nine admitted V4 metadata functions with only schema, driver filename and namespace literals changed, and uses the three exact reviewed cross-route selection/grid guards. Model initialization and native functions are never imported from the cross coordinator.

Inputs: explicit manifest path/SHA arguments for all intended existing canonical, historical, sentinel, B36 continuous and cross namespaces. The cross plan must bind exact epoch4, original16-case/repeat4 proposal, the two registered routes,40 ordered jobs, existing source metadata, one worker/inner thread and original timeout formula. No endpoint epoch6 or invented cross route is admitted. Existing metadata-reader snapshot and base inventory semantics remain in force. Actual collection also observes current recorded PID/creation identity; it is not an independent census of unrelated processes.

Cross completed cells require exact source/profile/gallery/epoch/native RESULT/finalization, CELL_ADMISSION/OUTCOME, COMPLETE/artifact list, actual worker argv, matching SPAWNED_PROCESS/LAUNCH and current recorded-owner closure. The cell's quiet-lease content must match a uniquely archived released cross coordinator lease. The outer index/reused references remain bookkeeping, never additional physical sessions. The internal native result retains its historical helper schema, but V6 records source_kind CANONICAL_SINGLE_SCENE_PAIR and never calls it a continuous composition.

Every successful pre-identity SPAWNED_PROCESS is one attempted physical spawn even when LAUNCH is absent. Creation remains null; no PID-only process query or inferred creation time is used. A matching successful spawn plus LAUNCH is one attempt. Failed/partial/unverified chains and completed native sessions remain separate. Incorrect argv or metadata cannot establish model completion. Unknown-creation coordinator children remain unverified owners and cannot support a released lease. Closed/logical/native and physical/reused counts have separate fields. Malformed metadata without an admissible spawn identity creates explicit coverage uncertainty, not an invented attempt count. Native payload bindings are declarations; downstream analysis must hash actual payload buffers. No raw audio, model, event, or trajectory files are opened by this adapter.

Outputs: the inherited fresh metadata snapshot plus INVENTORY_V6_RECEIPT.json and cross_paced_v6 section with exact source bindings, per-plan statuses/index-reference counts, physical attempts, logical completions, verified native session completions and unverified successful spawns. Sources are preserved in snapshot files. Missing prepared manifests and unknown lineage stay explicit. No whole-study completion is inferred. Inputs can be live and inherit non-atomic metadata observer limits; use after writer closure when final accounting is required.
