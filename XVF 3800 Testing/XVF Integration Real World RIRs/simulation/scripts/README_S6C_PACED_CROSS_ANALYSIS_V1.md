Inventory V6 must match the pinned independently reviewed revision. Outputs: REPORT/paced_cross_analysis/<namespace>/PLAN.json, individual cell observation receipts and predictions, separate repetition prediction indices, and RESULT.json or a preserved failure. Repetition one has 32 route/case cells, repetition two eight. These dependent repeats are not pooled as independent scenes. Core/name score arithmetic stays in the existing held scorers, executed separately on each index.

Only safe_output, prepare and run are privately compiled from the held canonical converter. The only two literal changes are the output namespace. The adapter supplies a strict cross-only V6 metadata interface and source/schema bindings. Both prepare and run enforce cross-only admission; an edited analysis plan cannot use V6 delegation to accept a canonical, sentinel or continuous schema under the cross label. Original canonical globals, native extraction, shared-policy parity, actual emission measures, process statistics and source-support/name API remain unchanged.

The native producer's ASR and identity paths are each checked against their own route. Prediction stream remains the ASR tap; identity_tap remains the other tap. The original name/support API deliberately selects the identity-tap support on the shared source clock, once. It does not substitute identity audio into the lexical ASR route or silently assume both taps are the same. These C085/C086 conditions have identity.mode=none and no gallery; running the unchanged descriptive name API does not establish known-person accuracy.

Actual wall emission and source-span-attributed processing time remain separate from modeled availability, phonetic/current-speaker/GUI latency and reference correctness. The same-native prediction retains the canonical transformer as its internal orchestrator; outer receipts also bind this wrapper and reviewed V6. PCM/model bytes remain transitively admitted by the native completion; no new audio read or neural inference occurs here. A post-closure policy replay is used only for exact native logical parity, and is reported separately from native timing.
