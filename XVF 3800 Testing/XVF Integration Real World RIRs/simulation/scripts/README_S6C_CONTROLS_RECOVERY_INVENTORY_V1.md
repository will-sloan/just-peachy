Its original failed SCANNER_OUTCOME, dispatcher failure and missing G: QUIET_OWNER_CLOSED.json remain unchanged. This helper changes no source, lease, native result or score.

## Inputs and outputs

Input1 is an explicit path/bytes/SHA256 binding for the root-executed recovery RESULT.json. It must state EXTERNAL_ARCHIVE_RELEASED and carry the exact authority/admission/audit/failed-original/archived-lease chain. Input2 is the explicit V7 observer index containing the original failed observer. The failed observer's exact sources, argv and storage counts are still verified by unchanged V7.observer_exit.

Every reader attaching the recovery checks all162 original recorded PID+creation identities and the housekeeping recovery process are closed. The two original parents and recovery process are rechecked at invocation gates; each native cell retains its original held owner checks. This is recorded-owner closure, not a global process census. Any present shared lease, original G archive, extra invocation, changed evidence, incomplete cell, live or unknown required owner causes rejection.

The private API is make_inventory(recovery_binding). It returns V7-compatible APIs and delegates every unrelated manifest unchanged. admit_observer_index(reader,binding) first performs exact held V7 index admission, then attaches the explicit recovery. invocation_rows returns the original producer status COMPLETE and reported_completed80 with original_closure:null, original_coordinator_exit_code:1, original_scanner_status:FAILED, original failed observer_error, and closure_kind:EXTERNAL_ROOT_RECOVERY_EXACT_ORIGINAL_LEASE. The closure binding points to the externally archived original lease. This is not an original successful coordinator exit.

collect_job preserves the complete native physical row, identities and counts; it adds recovery provenance. No physical attempt or model session is added by housekeeping. collect is the identical held V7 collection code in private globals using these metadata callbacks and augmented source bindings. Unlisted/unknown/failing other branches remain unchanged. Final whole-study collection still requires the separately reviewed fresh offline refresh; this helper does not turn an old snapshot into a current census.

CLI admit performs only the finite80-cell metadata admission and writes one RESULT.json under REPORT/runtime_failure_review/recovered_inventory_admission/NAMESPACE. It reports original native-cell status and external closure separately. It does not execute a whole inventory, analyze payloads, score results or authorize further runtime. MetadataReader retains exact consumed source buffers. Native events, audio, vectors and model files are never read here.
