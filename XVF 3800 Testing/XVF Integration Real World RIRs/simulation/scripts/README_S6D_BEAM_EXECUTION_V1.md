`s6d_beam_execution_prepare_v1.py declare` takes a fresh `--output` directory. `bind` additionally takes `--plan`, `--catalog`, `--stage C_collection|main_core|stream_diagnostics`, a fresh `--output`, and an accepted `--calibration` for main_core. Catalog schema is `s6d-native-capture-catalog.v1`, status `ROOT_ACCEPTED_CASES`, with unique rows `{case_id,capture_profile,case_result,qualification,calibration_partition?}`. Bindings are exact absolute path/bytes/SHA256. Qualification requires `edge-s6d-route-qualification.v1` PASS for the exact original case/configuration and true stream identity, common frame origin and source-tail proofs. C rows additionally need an actual disjoint C partition containing the exact original case result; uncaptured preparation is insufficient. Missing declared captures reject instead of shrinking the panel.

Binding creates metadata-only native views that change precisely declared `_raw` name aliases, preserving every original WAV/hash/gain/frame/route and binding the original case and root proof. No audio is normalized, resampled, independently trimmed or rewritten. Source payloads are read to predeclare the exact existing AudioJournal float32-to-PCM16 representation once at unity, shared by controls and variants. Historical O0+3dB audio is a different condition. `MANIFEST.json` and small per-job settings/admissions are the outputs; proposed native artifacts stay in a fresh G namespace.

Both preparation and runtime require catalog/job case_id and capture_profile to equal the original physical attempt identity and configuration profile. Original attempt.source_audio, source_input.source and configuration.source_input.source must be identical exact bindings, with unchanged source bytes. A valid physical receipt relabelled as a different fixed-panel cell is rejected. Draft v1/v2 epochs are preserved; use the separately reviewed repaired freeze.
