   Fill the hardware profile from the real schematics/pins and trusted host key.
2. Install offline and run hash/import health checks before activation. Keep a
   compatible previous release and external personal-data backup for rollback.
3. Qualify the exact XVF USB firmware ABI and rebuilt ARM64 host/command map.
   Then test bounded Start/Stop and O0/O1 mono audio/gain once, by consent.
4. Verify the 480×800 physical client area, touch transform, zoom, rosters,
   buttons, all captions/Unknown behavior and full-caption rescue.
5. Test actual consenting-person enrollment, save, reopen, rename, import/export,
   delete, outsider/silence/overlap and model-specific namespace isolation.
6. Measure whole-app RSS/USS, OS headroom, CPU speed, sustained source pacing,
   power/temperature and eMMC writes with one candidate active. 2GB is a whole
   system limit. Repeat on 4GB/8GB only as separately labelled configurations.
7. Verify failure/rollback while preserving external profiles; test camera only
   on demand and BMI270 movement/settling/manual re-anchor after axes/clock setup.

denoising, acoustic bank or human enrollment ran here. Software emulation cannot
replace this list.
