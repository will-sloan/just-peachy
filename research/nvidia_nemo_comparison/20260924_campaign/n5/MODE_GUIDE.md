# One mode guide for every composition

The authoritative shared application guide is
[`prototype/MODE_GUIDE.md`](../../../../prototype/MODE_GUIDE.md). The same file
is included in the preserved immutable application. This N5 index adds no
backend-specific mode implementation and changes no font, paragraph or roster.

Mode expresses intent; backend selects models; O0/O1 selects a tap. Captions-only
keeps all words. Open enrolled modes require compatible reference evidence and
otherwise show Unknown. Selected modes narrow the actual query roster. Closed
roster is explicitly assumed identity, never proof of a recognized person.
Numbered Unknowns are anonymous continuity, not confirmed people. Spatial modes
retain their unavailable/missing-evidence explanation and folded-array limits.
Show all restores captions hidden by an optional display filter without changing
the inference roster. Unsupported capabilities must not silently switch models.

For this campaign, use saved mono WAV input only; skip the guide's future live
enrollment instructions. Existing simulated source delivery is not physical
microphone testing. No enrollment audio or research participant is installed
into a personal store by these packages.
