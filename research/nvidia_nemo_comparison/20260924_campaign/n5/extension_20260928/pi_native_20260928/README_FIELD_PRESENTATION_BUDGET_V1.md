# Selected presentation write and Stop adapter V1

Purpose: bind GUI presentation receipts to the retained GroupWriter and keep a publication failure visible through the installed command worker's error reset and Stop. This is detached selected-method qualification. It does not instantiate the installed Controller, start a source/model, create Tk widgets, capture audio or change a release/pointer. The new class constructor explicitly rejects use as a standalone controller. A future live overlay must separately bind and validate the complete installed path.

Exact installedv12 controller source and retained isolated source hashes are admitted before execution. AST compilation selects record_presentation, _enqueue, _commands, stop and _do_stop without importing the full app. Only the presentation persistence try block is replaced; the worker's error reset now keeps the presentation error and its finally reasserts that error before task_done. _enqueue/stop/_do_stop bodies are unchanged; the wrapper writes a reserved closure after original Stop returns or raises. Record projection/count/recent-list semantics are retained. The source's exact selected _error body is exercised on RuntimeError with a detached object; its LiveTimingError branch is excluded, not qualified. Cleanup and playback are counted stand-ins, not physical device operations.

An exact descriptor binds source paths/hashes, adapter/helper, allocation hash, scope and named telemetry/failure/closure groups before a fresh layout is created. The four-directory layout checks actual metadata plus64KiB growth under the1MiB/128directory allowance, covering only these selected groups. gui_presentation.jsonl uses telemetry; the first rejected exact UTF8 payload and bounded diagnostic use failure; PRESENTATION_CLOSURE.json uses closure_reserve. Finite JSON and whole first/append writes use GroupWriter ceilings. First failure latches per epoch. Source Stop Event is set before diagnostics or queueing; the exact selected source _error also receives the failure. A full queue cannot prevent that source signal. The worker finally restores ERROR even when a queued action reset error or Stop reported STOPPED. New receipts after failure do not retry publication. Diagnostic or closure budget failure remains explicit. Cleanup exception details remain in bounded metrics even if closure publication fails. Closure logical_success is false on presentation/cleanup failure; a cleanup return is not proof of physical closure. A missing/unsupported source Event is reported, not silently credited as stopped.

Inputs: fresh CPU14 census, exact retained v12 controller and V76 isolated source, unchanged GroupWriter/allocation, authority and source-bound admission. Six malformed descriptor fixtures reject before layout: fields, scope, group, map, source pin and over-budget. Seven selected-method cases: mapped Unicode/escaped receipt, first-write quota, append quota, full command queue, cleanup exception, diagnostic quota and closure quota. Seven real short command-loop threads join; no controller constructor or child process. Full-queue case first runs a queued no-op to verify error persistence, then explicitly invokes selected Stop with cleanup stand-ins. No unchanged healthy controller/transport/timer/sourceStop test is repeated.

Outputs: private field-presentation-budget-v1 target, field-presentation-budget-v1-evidence host folder, descriptors/group receipts/PRESENTATION_CASES/RESULT/live envelope/owner records, independent review and exact backup. Synthetic text is private; no audio/transcripts/weights/gallery are committed.
