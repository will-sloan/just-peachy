application rather than simply choosing its backend. The earlier portrait
application's tabs, layout and settings were the interface the operator wanted.

fault. Their original SOURCE_CLOSE records report closed stream/released lease,

The requested backend combinations, Sherpa/PnC, separate ReDimNet/TitaNet
galleries,300second ordinary policy, recording UUIDs, capacity safety, postStop

runtime. No model weights, identity thresholds, acquisition geometry or

recording-count controls are omitted. Enrollment/gallery editing and playback
remain explicitly unavailable in this facade rather than presenting inert
controls as working features. Exit returns to the desktop; autostart stays off.
The engine carries the existing ASR event's final boolean in caption provenance,
so speaker stability is not mistaken for final transcription. It does not change
the ASR text or infer a new finality signal.

At the next separately authorized live Start, `recover_previous_source(manager)`
may handle only the exact current-boot, fully closed AEC255 fault. It verifies
owners/capture, the existing tool, current shared service, storage/RAM floors
and exclusive leases. Two independently read-back tool/config restore copies
precede commands. It reads VERSION/build/AEC; a readable AEC sends nothing.
Only the same exact current failure permits one durable intent and literal
`TEST_CORE_BURN 0`. It waits2seconds and requires unchanged firmware and fresh
AEC readability. Uncertain/failed attempts are preserved and never automatically
resent for that fault SHA. This is conditional recovery, not a periodic reset.

XMOS documents that [TEST_CORE_BURN0 forces a firmware reboot, restoring internal
parameters to power-on defaults](https://www.xmos.com/documentation/XM-014888-PC/html/modules/fwk_xvf/doc/programming_guide/04_testing_the_software.html).
The old unreadable volatile DSP state cannot be backed up or claimed restored.
The application must still apply its ordinary route during the new source Start.
We never enable core burn with1. Closed-stream readability alone is not capture
or model qualification.
