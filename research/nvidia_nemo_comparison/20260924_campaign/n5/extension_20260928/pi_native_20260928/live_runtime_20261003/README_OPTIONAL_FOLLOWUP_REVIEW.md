# Closed optional live-followup review

`review_optional_followup.py` reads a fully closed, independently mirrored live300 optional qualification. It rehashes every listed file, checks natural unit/owner/lease closure, exact requested/executed policy and package, all primary/raw sample intervals and hashes, child EOF/source hash or explicit fallback, and sampled whole-cgroup resources. It counts optional-prefixed revisions separately from primary label revisions. No transcript, voice identity, audio or probabilities are printed.

Inputs: the complete monitor directory and the exact prepared payload (its expiry may remain zero because the reader does not dispatch). Outputs: a new private CPU14 owner directory and bounded `REVIEW.json`, with `reviewed=false` and `production_eligible=false`. A human-reviewed normal admission is a separate action. This program cannot authorize a native job or promote a package. The CPU interval is explicitly recorded; sampled memory is not a guaranteed peak. No quality or sustained performance claim follows from completion.

Command Prompt and Anaconda Prompt use the same command without `&`, with double quotes in place of single quotes. Use the existing interpreter and environment. The program immediately pins CPU14 and durably registers its numeric PID/create-time before project reads/imports. It imports the exact SHA-pinned existing bounded reviewer after that registration, loads no models and contacts no device. Wait for `MIRROR_COMPLETE.json` and the root's host-Python release before running.
