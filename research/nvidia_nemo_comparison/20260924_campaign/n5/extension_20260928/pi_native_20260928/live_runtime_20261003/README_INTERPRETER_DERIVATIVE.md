# Prepare the exact interpreter-validator derivative

`prepare_interpreter_derivative.py` is host-only: it copies exact frozen disabled
activity11, changes only `release_authorization.py` and its paired README, and
builds independent disabled12. It verifies the entire source manifest before
and after, exact replacement pins, unchanged other content/operational fields,
and independently reads back backups. No Pi, model, desktop, production
authorization or native admission is performed. This supersedes the earlier
path-only12 plan: production13 may be a later separately reviewed relocation.

Inputs: exact activity11 snapshot, its DERIVATION.json, the two reviewed repair
paths and SHA256 pins, a reviewer and fresh private output parent. Outputs:
package, deterministic compressed archive, BUILD_RESULT.json, predecessor and
DERIVATION.json, source copies and independent repair backups. The content review
never claims12 native execution. The builder enforces existing finite package
and storage bounds; CPU14 and actual numeric owner registration precede reads.

PowerShell (qualified interpreter from README_PACKAGE.md; literal pins come
from the reviewed repair receipt, never inferred from an untrusted payload):

```powershell
& $PY -B "$N/prepare_interpreter_derivative.py" --source $S --prior-derivation $D --replacement "$N/release_authorization.py" --replacement-sha256 $CODE_SHA --readme "$N/README_RELEASE_AUTHORIZATION.md" --readme-sha256 $README_SHA --reviewer 'reviewed exact interpreter asset correction' --output-root "$B/live-runtime-20261003/audit-preparation"
```

Command Prompt and Anaconda Prompt:

```bat
"%PY%" -B "%N%\prepare_interpreter_derivative.py" --source "%S%" --prior-derivation "%D%" --replacement "%N%\release_authorization.py" --replacement-sha256 %CODE_SHA% --readme "%N%\README_RELEASE_AUTHORIZATION.md" --readme-sha256 %README_SHA% --reviewer "reviewed exact interpreter asset correction" --output-root "%B%\live-runtime-20261003\audit-preparation"
```

Set S to the package under `activity-derivative-e9f5bf8bb6ea42e6965328bc3e13a0c9`
and D to its DERIVATION.json. Run only the focused interpreter check documented
in [README_RELEASE_AUTHORIZATION.md](README_RELEASE_AUTHORIZATION.md) when
verifying this change. Fresh native admission follows actual closed-job baseline
review and is passed separately to prepare_package.py against the resulting
immutable12 snapshot. It is not generated by this helper.
