# Focused same-Start readiness check

Purpose: check the changed shared Start continuation and manual/finite helper
lifetime checks on the HOST before native staging. This executes the actual
eight extracted current Manager methods and actual `unit_checks` function AST.
It reads the actual retained `qualifying_fault` AST and requires one complete,
hash-matching real AEC255 source failure from a private inspection receipt.

All execution owners, process/thread handles, authorization callbacks, helper
completion, systemctl/cgroup replies and runtime paths are explicit synthetic
fixtures. Runtime control/source/session files exist in memory only. The check
never imports runtime models, launches a process/helper, contacts the Pi,
captures audio or sends a firmware command. It is not native closure, source,
reset, GUI, accuracy or performance evidence.

Inputs: current `launcher.py`, unchanged `xvf_readiness.py`, current
`xvf_readiness_helper.py`, this check and README; plus a bounded closed private
inspection `RESULT.json`, and the exact source owner's PID/start ticks/boot to
select its full `work/source/SOURCE_CLOSE.json` record. The source record must
match its published SHA and the retained qualifying predicate without adding
or inventing fields. Original private failure bytes remain unchanged.

Outputs: a unique private CPU14/exact-FILETIME registration, original 2MiB/
600-second scope, all source backups plus independent restore copies/readback,
`SOURCE_CLOSED.json`, compact actual-input hashes and `RESULT.json` containing
eight positive groups and six owned-unit rejects. Host C:50GiB/G:75GiB floors
remain. Root independently verifies the actual host owner is absent afterward.

The eight groups cover:

1. Existing qualifying failure: the same Start waits for one helper, then starts
   one fresh worker with the unchanged selection.
2. New first-source fault: natural worker/source closure precedes helper and
   continuation of that Start.
3. Stop cancels pending readiness and prevents a fresh worker.
4. A second AEC fault after continuation does not create a retry loop.
5. Healthy Live skips maintenance.
6. Saved input skips a historical physical microphone fault.
7. Explicit manual lifetime accepts None only with actual infinity and exact
   owned-unit members; finite lifetime/MainPID/extra-member drift reject.
8. Finite lifetime retains remaining-time and actual-runtime checks;
   infinity/mismatch/insufficient deadline reject.
