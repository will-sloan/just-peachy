# Export the actual finalized kept session

Purpose: prepare the existing unchanged full-application selected ZIP exporter
for an actual successful build25 recording. Source audio, all original model
events, captions and provenance remain private. The source recording is copied,
never deleted. The helper does not run models, capture, GUI or native actions.

Inputs: actual launch JOB, its complete independently closed original and
finalized monitors, actual successful native finalizer dispatch result and
explicit unused export label.
The helper binds all original workflow fields and exact session ID to the real
returned NATIVE_CHECK_V2 PASS, current boot and package25 manifest. It refuses
failed/incomplete/discarded sessions and never synthesizes native proof.
The full existing mirror verifier is reused for the finalized observation with
only its exact folder suffix changed; all owner, hash, natural exit and cleanup
checks stay exact. Actual native-file bytes/SHA are independently copied and
compared to the real finalizer response.

Outputs: fresh CPU14-owned private source/action/README/input/payload copies,
independent restores and compact source closure. Preparation2MiB/600s; fresh
native and independent PC export reserves256MiB each, payload590s. Existing
source/package/storage/owner/leases/finite file/ZIP peer accounting guards stay
unchanged. The native exporter itself rechecks native proof and exact source
job closure, derives the complete selected ZIP allocation before launch, and
uses a read-only store. A later complete PC hash/readback is still required.
