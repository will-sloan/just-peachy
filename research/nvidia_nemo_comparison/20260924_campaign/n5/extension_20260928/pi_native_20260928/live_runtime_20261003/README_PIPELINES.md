## Integration contracts

Use `RuntimeSelection.validate()`, `SessionPolicy.validate()` and
`get_profile(selection.nemotron_profile).native_name` before native acquisition.
`bind(native, selection, policy, runtime_document, timing_callback=None)` requires
the existing runtime-document keys `nemotron_model`, `nemotron_library`,
`nemotron_library_sha256`, `native_runtime_files`, `streaming_profile` and
`native_device`. Resolve model/library/runtime-file paths to the selected retained
campaign directory first. The caller must verify the full installed asset and
module manifest before binding, enforce process limits and retain receipts.

CurrentDelayed reuses its retained delayed LRU1 library; every other profile uses
the retained streaming/Chunk52 LRU8 library. The wrapper checks the selected core
and C-ABI wrapper pins, the exact adapter source, and every actual submitted
geometry field plus preset before calling `nemo_speech_diar_create`. It does not
use the old fixed three-mode guard for the new profiles. Existing descriptors
cannot be changed; new ones are registered explicitly. A fresh process is
required between independent sessions or native library selections.

The native output workspace reserves `(maximum_samples // 160 + 1) * 8 * 4`
bytes, with its maximum samples derived from session policy. Each update still
uses the real full retained-probability ABI. No range API is invented. New output
rows are copied into immutable arrays before workspace reuse; native compaction
must not skip undelivered rows. The source-derived EOF rule is zero rows for zero
samples, otherwise `samples // 160 + 1`, retaining the endpoint frame. A native
run is still required to establish behavior for each newly admitted profile.
No measured speedup is claimed. A telemetry callback failure is counted and
cannot lose an already produced model update.

For captions, call `advance(received_sample_count)` as the source progresses,
then `add_caption(increasing_sequence, interval, text)`. Emit its returned events
immediately, including unknown/provisional speaker labels. `apply_fast(spans)`
adds persistent fast-pass evidence. `apply_refinement(pass_id, spans)` aligns
independent local speaker slots using a one-to-one maximum overlap assignment;
ties and weak evidence remain unresolved. It can return `speaker_alignment`
events containing exact sample intervals and `caption_revised` events referencing
their digest. Persist alignment events, and upsert captions by `caption_id` and
increasing `revision`; never append a revised caption as a new line.

Source/session/sample-clock mismatches fail. Revisions outside the bounded
window are dropped. Expiration or capacity eviction emits final fallback status
while retaining the text. Use `advance` after source stop to freeze remaining
captions once the revision window closes. State is single-owner; serialize calls
from worker threads at the controller boundary. Do not interpret speaker
agreement or these synthetic mapping checks as diarization quality evidence.

`RollingTelemetry` reports weighted RTF `sum(compute)/sum(audio)` over its bounded
time/event window. No observations gives `None`, not a fabricated zero.
`stop_required` and `FAILED_BACKLOG_LIMIT` require the controller to stop explicitly
and retain the processed prefix once the configured backlog limit is reached.
The same failure must be reflected in the session receipt; it is not successful
real-time completion. Optional refinement can be rejected on backlog or queue
capacity and expires at its deadline. Primary ASR text must continue independently.

`RefinementCoordinator` owns one optional injected worker thread. The controller
keeps caption-ledger ownership and calls `emit_primary` without waiting for that
thread, offers bounded source-reference jobs, and polls bounded results. New
overlapping pending windows coalesce; in-flight jobs retain their ID/deadline.
Worker errors and late results keep primary captions unchanged. Closing a still
running worker reports ownership failure rather than cleanup success. Native mode
requires an independently trusted SHA256 for a measured dual-worker CM5 receipt
covering both profiles, exact source/model/runtime, CPU envelope, peak memory,
positive CPU headroom, rolling RTF at most one and zero dropped samples. These
are the older draft coordinator's own gates, not the admission rules for the
implemented `optional_d1_refiner` child. The latter reviews primary protection,
source continuity, bounded lag/fallback, memory and closure with explicit
timing denominators; it does not invent a summed combined RTF gate. No usable
native integration is supplied for this older draft coordinator.
The launcher must reject provisional mode until both admission and native worker
integration are present; synthetic injected workers cannot admit that mode.
