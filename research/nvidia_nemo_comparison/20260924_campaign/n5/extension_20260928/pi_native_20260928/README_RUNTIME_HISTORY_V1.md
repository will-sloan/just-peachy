# Read-only recording history

field_runtime_history_v1.py reuses the exact hash-pinned installed SessionStore list/rows methods and compact decoder AST bodies without importing model modules or constructing a Store. It accepts complete five-file Audio Off or seven-file Processed archives, verifies all member hashes before and after, refuses writes/processes on its calling thread, and bounds source reads, time, rows and output. This cooperative audit guard is not a kernel sandbox. Inputs: installed release and manifest SHA, verified closed conversation path and metadata pin, monotonic deadline. Output: original reconstructed caption rows, metadata and complete member pins; no playback or writes. Embedded unchanged in manager10 to retain the16-module capsule bound.

Operator: use the installed desktop profile, then Saved recordings, select a closed recording, Open selected recording, and Back. History is read-only; use the documented offload command for verified PC copies. Renderer API: render(release_id, policy_sha256, rollback_sha256). Native integration remains unexecuted until its separate receipt.
