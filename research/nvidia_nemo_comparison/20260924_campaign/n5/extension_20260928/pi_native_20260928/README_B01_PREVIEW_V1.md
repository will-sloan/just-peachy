# B01 retained-ReDimNet saved-file preview V1

Purpose: a bounded, explicitly selected native CM5 preview of Sherpa captions + one delayed Nemotron D1 stream + the unchanged ReDimNet encoder. The shared application is the qualified deferred-SciPy source; only the external preview wrapper and explicit launch mode are new. This is an experimental saved-file mode, not a release, speech-quality result or persistent personal naming. The new research gallery is empty: raw personal identity remains Unknown while the presentation uses anonymous session speaker numbers.

Inputs: authorized CM5 and existing strict SSH key/host identity; qualified `b01-restart-gui-v1` source/admission plus D1/E0 reference and label reviews; original 16kHz/mono/PCM16/715127-sample WAV; fresh host census and target ownership/RAM/disk checks. No downloads or new assets. The retained original app remains active and unchanged.

`launch_b01_preview_v1.py` creates a unique private run for each user invocation. `b01_preview_gate_v1.py` shares the existing target nonblocking B05_PREVIEW_DISPATCH flock, checks every owner by boot/PID/start ticks, rechecks resource/source identities and holds the lease through systemd completion. It publishes DISPATCH_OWNER.json so other launchers reject overlap. The app verifies its admission, bound files, 768MiB hard address-space limit, CPU2/3, quota200%, native/Python stacks1MiB and one native model thread. Target available RAM>=850MiB and free disk>=5GiB; host C>=50GiB/G>=75GiB; combined output reserve48MiB within existing 1GiB allowance. No larger memory cap or OS change.

User flow: the window starts idle without inference or a selected file. File / Choose saved sample selects only the admitted original44.7-second file. Start file processes it silently at original1x pace; Stop drains; a subsequent Start restarts from sample zero. Captions arrive before delayed speaker labels (about27seconds on the current sample). No audio playback or microphone capture. At most two starts, each with75seconds remaining before the145second application window; automatic Close and180second service bound. Other modes, backends, enrollment, personal profiles, capture/playback and other files are rejected at the command boundary. A fresh empty private data directory is used for each launch. The original install/autostart/data are preserved.

Outputs: private admission, host/target census, exact dispatch/service owners, logs, session journals/archives, RESULT and snapshots. Every later user run needs independent source/sample/E0/D1/closure review. It is not accepted merely because a prepared launcher exits successfully. Physical display/touch/layout, real speech, 48kHz live-resampling memory, long-term stability and B02 remain separate gates. Never launch user mode on an automated wakeup.
