# Operator copy-to-PC v3
Purpose: Copy a CLOSED recording or its independent Pi-local backup into a fresh private PC folder. Run once for original and once for local to preserve both separately. The working route and all native originals remain unchanged; no automatic deletion.
This is an operator read-only command usable after delivery. Each invocation issues a fresh600s copy-only admission, independently reserves155669036B plus4MiB metadata, reads all prior owners/lifetimes and measures current host/target usage. It does not extend campaign work or authorize recording/model changes. C>=50GiB/G>=75GiB/Pi>=5GiB remain, plus full host copy reserve. Two105s transfer phases are separate commands so the original frame/wire ceilings are unchanged. CPU14 host; nativeCPU3/128MiBAS/1MiBstack/FSIZE0/alarm150s.
Inputs: current installed candidate receipts, prior binding and last inspection, local/private evidence roots, recording-01..04, original/local, and an ABSENT output directory. Current manager must be idle with capture off; its historical recording owner can differ after a verified restart. Stopped but unresolved or incomplete recordings reject. Cancellation has recording_created=false and is never certified as a recording.
Outputs: fresh admission and measured census, original full metadata/file membership with empty directories, per-file SHA256 and full disk readback, exact exporter closure, BACKUP.json. A partial destination is preserved on error and is not a backup. No overwrite or retry into that directory.
PowerShell, from native source directory:
    & 'C:/Users/amiri/Documents/GitHub/just-peachy/.edge-speech-env/python.exe' -B export_runtime_recording_v3.py --local LOCAL_ROOT --private PRIVATE_ROOT --prior-closure PRIOR_BINDING_JSON --previous-inspection LAST_INSPECTION --candidate-install SOURCE_INSTALL --active-install CURRENT_INSTALL --slot recording-01 --root-kind original --output NEW_PRIVATE_ORIGINAL_COPY
Repeat with --root-kind local and a different absent output to independently transfer the Pi-local copy.
CMD / Anaconda Prompt:
    python -B export_runtime_recording_v3.py --local LOCAL_ROOT --private PRIVATE_ROOT --prior-closure PRIOR_BINDING_JSON --previous-inspection LAST_INSPECTION --candidate-install SOURCE_INSTALL --active-install CURRENT_INSTALL --slot recording-01 --root-kind local --output NEW_PRIVATE_LOCAL_COPY
Both invocations retain the full original reservation; a smaller recording or deleted file gives no replenishment. Use the final mode guide for concrete installed paths. Existing Python environment and SSH key are required; no downloads. Sources must be backed/restored before use.

--candidate-install identifies the recording source release; --active-install identifies the currently idle frontend. They can be the same. Separate exact policy hashes permit copying a preserved older release while the current frontend stays idle. Every source owner must be dead; only the exact current manager is permitted alive. No other source/helper may be active.
