# Archive budget review addendum

The bound README and successful native fixtures remain unchanged. After the run, static review found that exact initial64KiB control validation has no reserved growth for final fields. `EpochArchive.close()` can therefore reject final publication for a near-full initial document; existing metadata is preserved, but a fresh joined receipt is not guaranteed. This was not exercised or observed in the14-case native protocol. See FIELD_ARCHIVE_BUDGET_FINDINGS_V1.md and private CODE_REVIEW_V1.json. No general finalization or installed/live acceptance is claimed. The next derivative must test that distinct boundary; no unchanged successful model or capture rerun is needed.

The independent reader intentionally does not compare the case checkpoint hash with the final epoch JSON after repeated close: close legitimately changes updated_utc. It verifies the durable final state/counts/bounds and all source/admission hashes. Full target backup independently verifies the final bytes. The run, independent-reader and backup commands for PowerShell/CMD/Anaconda are in README_FIELD_ARCHIVE_BUDGET_V1.md; their outputs are exclusive and must not be recreated.
