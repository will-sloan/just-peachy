# Runtime census/export wrapper
Current entry: mirror_field_runtime_v1.py. See README_FIELD_RUNTIME_EXPORT_V1.md for partitioning, limits, source graph and the changed host fixture.

Purpose: finish items F04/F16/F25 by connecting the prepared native bootstrap/exporter to the bounded host receiver, independent native closure and preserved PC copy. No activation, recording, deletion, model execution or payload writes on the Pi.

Inputs: a fresh local JSON envelope with request, modules, loader and host. The request carries a fresh finite admission, exact Policy3/manifest, actual external owners, packed prior owners, fresh boot/configuration/lifecycle evidence and optional earlier census index. Host fields pin every source, coordinator, a compact fresh complete owner/lifetime preread, output/destination, original 3,670,016-byte metadata groups and the independently completed census RESULT for export. Source backup and independent restore precede use. All historical owners must still be read by the preread; compact receipts contain counts/digest only. Missing evidence rejects before SSH. This API requires a real issuer; an illustrative envelope is not authority.

Outputs: fresh immutable output directory with early owner, admitted request, graph, ready/census/partition receipts, bounded raw stderr/failures, actual exporter closure, closure utility identity/absence and host logical completion. Export additionally creates the sibling -mirror directory, hashes every file again after natural native exit and exact closure, then publishes BACKUP. Failure preserves all bytes and creates no success receipt. Host logical completion does not assert its own physical death.
