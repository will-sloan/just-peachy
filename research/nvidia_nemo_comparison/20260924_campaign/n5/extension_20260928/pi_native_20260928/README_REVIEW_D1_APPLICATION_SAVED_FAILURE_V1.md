# Saved application V1 failure review

Purpose: preserve the actual V1 pre-model widget failure, not reinterpret it as success. Input is the closed d1-application-saved-v1 target, its immutable admission/sources and raw FAILED_PRESERVED receipt. The installed UI button helper returns a holder Frame with a .button child. V1 stored the holder and failed on navigation invoke before selection or model startup. Its success reader is unused.

The new read-only reader requires this exact failure, exit1, false logical_success in both outer closures, empty passage directories, the original close receipt, absent/free application lease and exact dead process identities. It verifies baseline/capture/leases and actual limits. It does not claim D1 Start/Stop, model inference or a successful application test. Output is private FAILURE_REVIEW.json followed by exact private target backup/BACKUP.json, all within the V1 host allowance. No dispatch, source change or retry.
