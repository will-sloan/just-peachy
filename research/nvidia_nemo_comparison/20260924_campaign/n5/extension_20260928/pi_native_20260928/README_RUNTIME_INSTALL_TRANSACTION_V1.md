Purpose: F04/F06/F07/F17/F18. Prepare one finite, backed transition from the original idle app to the six-profile offline runtime. This installer is PREPARED and requires the host issuer/receiver; it has not been run on the Pi.

It checks the current boot and exact original launcher/app PID-start identities, capture/leases, physical32GB device, display270, disk floors and measured independent reservations. It creates exact startup/config backups and independent restore copies, arms the local rollback service, then requires the PC to persist and read back those backups before normal Tk WM_DELETE_WINDOW. It identifies the actual Tk interpreter by its PID; it does not use a remembered widget or kill the old app. After exact natural closure it checks the unchanged850MiB initial RAM floor, streams pinned files in16KiB chunks, copies the compatible gallery read-only, publishes the manager policy/control files and installs profile shortcuts. Failures preserve all partial files and consumed roots. The local OnFailure service restores the old autostart and opens the preserved baseline idle, subject to its exact capture/settings/process checks. A source review is not proof that rollback works on the device.
