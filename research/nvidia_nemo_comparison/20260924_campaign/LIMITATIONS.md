# Evidence boundaries and deferred work

The Pi is powered off and disconnected throughout this campaign. Its historical
rc5 deployment/source receipts are preserved; N1 makes no current Pi, microphone,
physical touch, camera, sensor, ARM64 performance or 2 GB total-system claim. No
OS/firmware changes, remote Pi operation or personal-gallery migration occurred.
All actual GUI renders use a separate Windows desktop without switching the
input desktop or injecting input. This preserves the user's working desktop.

The first legacy focused test run did not install the later global endpoint
inventory guard: legacy Controller construction includes read-only endpoint
observation. That run must not be cited as proof of zero endpoint enumeration.
The final full suite and installed-entrypoint audit explicitly disable or guard
enumeration/capture/playback. No microphone streaming or hardware speech session
was used for N1, and saved-audio inference disables endpoint/IMU startup itself.

Timestamped caption spans record ASR revision windows. They are not phonetic
alignments: exact word/phone truth is absent. First proposed/source labels and
first actually applied Tk labels have separate records. Tk application time
does not prove viewport visibility or physical scanout. Final-snapshot GUI
replay verifies the real common UI and complete retained text; it is not the
online paced rendering latency of those audio runs. Source-event A/B/A,
interruption, simultaneous and late-correction fixtures supply the specific
identity-revision coverage; an absence of revisions in a neural run does not.
The baseline also emitted one false one-word final utterance on each tap of
noise-only S45_12_20. Digital-silence S45_12_15 emitted no text. Passing N1
execution/integrity checks does not mean the baseline has no recognition errors.

The 48-scene screen is predeclared and contains difficult/incomplete/empty cases.
It is not a population accuracy estimate or the entire 240-scene comparison.
All 240 remain bound for later stages. Exact lexical scoring is limited to
reference-supported conditions; activity timing is approximate. Source-script
punctuation is not independent conversational gold. The 50 ms corpus convention
is not measured physical latency. No historical neural outputs replace the new
baseline runs. The original C105 ordering replay is a separate historical
source-event diagnostic, not proof of current neural identity accuracy.

E/C/Q source clip IDs, file/PCM hashes and prompt groups are disjoint under the
documented audit. Speaker identities intentionally recur across E/C/Q. Undocumented transformed aliases and unique-human re-identification are
not exhaustively ruled out. Processed E has a declared same-device configuration
shift. Processed C is collection-only until its projection/threshold admission
is reviewed. Clean references remain a separate domain condition. No personal
recordings or incompatible ReDimNet vectors are used for TitaNet.

Only the baseline backend is executable in this N1 GUI. Six planning compositions
are explicitly unavailable. Staged official assets and a successful native CPU
build do not establish candidate inference, parity, ARM64 support or feasibility.
A1/E1 need an isolated reviewed NeMo/export environment; X1 is optional/deferred.
Standalone new NVIDIA punctuation weights remain unverified. Candidate adapters,
comparisons and model ranking belong to the following stages.

Automatic Codex continuation is not installed: the local CLI supports an exact
session, but no atomic guard against a competing live turn or duplicate prompt
queue was verified. Real OS probes and numerical workers run independently;
changed/error/completion requests are written for manual review. Unchanged
healthy probes invoke no LLM. Tasks require this user logged in, do not wake the
PC, and cannot run while Windows is asleep/off. Remove only the owned tasks at
the end of the entire campaign; stage completion alone does not erase supervision.

Two below-normal CPU workers are a Windows research throughput setting. They
are not an isolated resource/latency measurement or the one-stack 2 GB device
profile. Disk reserves are checked at launch and at the selected OS probe
interval; a breach stops the verified owned worker tree, preserving evidence.
The 96-hour finish time is a planning target, never a required delay.

WD-40 reconstruction remains deferred to N3: current vocabulary normalization
does not manufacture hyphen/numeral corrections. Existing Amir safeguards,
original text retention and source partitions have software tests, not a new
human speech-accuracy claim. Progressive adaptation stays off in the primary
comparison; hardware pin/address/controller fields remain unassigned/disabled.
