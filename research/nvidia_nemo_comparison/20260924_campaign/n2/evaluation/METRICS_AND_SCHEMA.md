# N2 metric and input contract

Amendment 01, declared before the full N2 screens after auditing reference coverage, makes the **zero-collar** 20 ms estimated-activity DER/JER the primary variant. The original 250 ms collar remains a mandatory sensitivity result, with both retained speaker-time and excluded wall-time denominators. `PROTOCOL_AMENDMENT_01.json` binds the unchanged original protocol and explains this reference-coverage choice. The first smoke's original score is preserved; V2 reports both variants. Neither is phonetic DER/JER.

The frozen manifest receipt binds the seven protocol/data inputs and all referenced waveform files. `AUDIO_ONLY.json` is the only query-job manifest admitted to the predictor. Its job keys are exactly `job_id`, `audio_path`, `audio_sha256`, `frames`, `sample_rate_hz`, `gain`, `reset_between_scenes`, and `tap`. Job identifiers are opaque scheduler identifiers, not actor/seat labels. The runtime must not open `EVALUATOR_TRUTH.json`, `ROSTERS.json`, or `diagnostic_Q_windows`.

`WINDOW_MANIFEST.json` has model-independent E/C `windows`, `gallery_templates`, and **evaluator-only** `diagnostic_Q_windows`. E/C windows contain identity for permitted gallery preparation/C evaluation, whole-waveform file hash, inclusive start/exclusive end sample, actual sample rate and gain. A template references window IDs, the unique source IDs, duration quota, actual estimated speech duration, whole-clip duration and shortage. Each model applies its own required preprocessing to precisely these waveform spans. Clean E/C are existing whole clips; the estimated activity is used to account for speech and weight clip vectors, never as a phonetic boundary. Processed E is a whole accepted captured file with separate stream and position. No output projection is inferred from its null delay. The original source-speech estimate is retained separately from full captured duration.

The 15-second tier means the frozen nested whole-clip prefix reaching roughly 15 seconds of estimated active reference speech, not a cropped 15-second waveform. Unique duration is never increased by a repeated clip, a second tap or a second recorded position. Matched 5/15/30 diagnostics use the intersection of identities available at all three tiers: 28 across the clean bank. The same frozen roster membership is intersected with that population for each tier; the intended-member denominator remains visible. Processed 5/30-second tiers are unsupported, because the accepted source plan only provides the existing processed 15-second acquisition.

`EVALUATOR_TRUTH.json` retains both taps for all 240 scenes. Each turn has its original transcript, source identity, whole-source support, saved approximate active intervals, role and missing-window reason. The source activity already contains the 800-sample convention. Adding the saved per-tap `source_with_rir_to_output_offset_samples` gives output activity; do not add another 800 samples. Whole source-file support adds the convention once to its unshifted source start/end. No fitted shift, audio gain, silence removal or timestamp clamp is allowed. An out-of-range support is unavailable with a reason. Independent scenes reset state; true turn boundaries never reset a model.

`scoring.activity_metrics` accepts seconds-based segments `{start,end,label}` from this evaluator conversion and the actually predicted timeline. Every start/end must lie in the file. It samples a 20 ms grid at bin midpoints, excluding the union of ±250 ms around every reference activity boundary. It reports actual evaluated wall duration and excluded duration, so dense approximate activity can leave little scored support. Overlap is included: reference speaker-seconds are the sum of active reference speakers times bin duration. An assignment maximizing reference/hypothesis intersection supplies the anonymous permutation. Miss is `max(Nref-Nhyp,0)`; false alarm is `max(Nhyp-Nref,0)`; confusion is `min(Nref,Nhyp)-Ncorrect`, integrated over scored bins. Approximate activity DER is their sum divided by reference speaker-seconds. JER independently minimizes per-reference `1-intersection/union`; unmatched reference speakers contribute one. Extra hypothesis speakers affect DER, not an extra JER term. Empty denominators produce null, not zero. Incomplete ambient truth produces an explicit unavailable result. These estimated-activity quantities cannot be compared directly with published phonetic DER/JER.

The paragraph above describes the original helper default and retained 250 ms sensitivity. The V2 runtime scorer explicitly calls the helper with collar zero for primary reporting and 0.25 for sensitivity. Native D1 endpoint overhang is retained in raw journals and reported separately; metrics intersect native frames with delivered real waveform support only, never reference-fitted bounds.

`scoring.cpwer` consumes raw ASR word streams grouped by actual predicted anonymous track; Unknown is its own hypothesis stream. Reference streams concatenate source words in temporal turn order per source identity. Hypothesis streams preserve each predicted track's temporal word order. The cost matrix contains ordinary word edit distances, with empty dummy streams for unequal speaker counts; the minimum assignment yields total errors/reference words. Whole utterance association is coarse if ASR word times are unavailable. cpWER covers complete-reference scenes only. Empty controls report inserted-word counts and null WER. Incomplete scenes retain explicitly target-conditioned analyses rather than all-speaker cpWER. `tcpWER` stays null because all admitted source `word_times` are null. Do not uniformly distribute words to invent it.

`scoring.asr_invariance` requires exact ordered raw word equality for label-only variants and supplies both hashes/counts. Formatted final text must be checked separately. Root streaming results must preserve first-visible, first-final and latest labels for each same span ID. It is invalid to silently choose the most flattering stage. A streaming label revision changes only the supported span interval and must preserve the ordered raw ASR words.

`scoring.turn_coverage` retains every source turn. A diagnostic turn maps to the track with the greatest total reference-activity intersection; no intersection or a tie is unresolved. A return is a later turn of the same identity whose onset is at least 2 seconds after that identity's previous turn end. Consistency, changed track and unresolved counts share the entire return denominator. A split is one resolved reference identity assigned to more than one track; a merge is one resolved track assigned to more than one reference identity. Both are coarse turn diagnostics, not proof of phonetic attribution. Short replies have at most 1.5 seconds of estimated active speech. Report short/total turns without any admitted embedding-window intersection. Embedding calls count actual evidence windows; unique evidence duration unions overlapping windows so repeats do not add duration. A window touching more than one source identity is contaminated even if those voices occur sequentially. This is broader than simultaneous acoustic overlap and must be named accordingly. Predicted window selection remains runtime-only; these counts are evaluator diagnostics.

Short turns additionally retain resolved and unresolved track counts. The screen summary reports active-reference speaker-seconds intersecting the union of any actual evidence windows, as well as the whole active-reference duration. This any-intersection coverage does not certify clean or usable naming evidence. Incomplete ambient references remain a separate class. Aggregate DER is micro-weighted by retained reference speaker-seconds; aggregate JER is an explicitly labelled macro mean of supported per-scene JERs. Both collar variants retain included/excluded speaker-time and wall-time denominators. The pure native profile runner reports native-activity coverage with no embedding-evidence claim; absent activity and unresolved ties remain different counts.

C calibration uses one maximal roster score and top1/top2 margin per unique C source, not every pair as an independent open-set trial. Target sources are identities with a compatible actual E profile; all other C identities are strangers. At least 100 negative source clips, 5 distinct negative identities and 20 positive clips are required. The fixed margin is 0.05 and the scalar threshold is the lowest value meeting an empirical false-known rate ≤1%. Source clips from the same person are correlated; the Wilson95 upper interval is descriptive under an independence assumption, not a certified deployment limit. Gate integrity binds encoder, preprocessing, windows, gallery, roster, domain, duration and dimension. Pairwise verification EER is reported only with both positive and negative classes and does not supply a naming threshold. No gate is calibrated on Q.

Only clean C has admitted source segmentation. The runtime query domain is processed XVF; its same-device C is collection-only. Consequently all runtime open naming gates are `UNCALIBRATED_REJECT_ALL`, even when clean C supports a component threshold. The clean C whole windows also differ in duration/selection from actual 0.5–2 second predicted windows. Closed-roster forced names are assumptions and remain unverified; separate their wrong assignment/stranger counts from recognized names. None, open, selected-open and explicit closed modes retain all scenes, including unavailable members and absent enrolled people.

Component model extraction is accelerated saved-file execution, not source-speed latency, integrated streaming or Pi performance. The common application runner owns the latter receipts. Baseline S45_12_20's one inserted word on each tap remains a failure example. Any unsupported capability, missing window or failed process is reported with its original denominator; it is not removed to improve metrics.
