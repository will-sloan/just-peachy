# Complete-panel observed-name diagnostics

Purpose: `review_name_panel.py` explicitly composes the qualified observed-heading
reader, evaluator reference join and conditional name scorer for every cell in a
complete stopped V2 application panel. The original runner, source and narrower
reviewers remain immutable. A passed main/modes comparison and shortlist must
already support the reconstructed production plan; this tool cannot create or
bypass that admission.

Inputs: `--run` is an existing immutable fully stopped V2 run. `--output` is a
fresh separate private directory under `local/n4`. All 40–240 planned cells,
ordered progress records, exact stopped owners and collected bindings must pass
the existing independent census. The expected denominator comes from the plan,
not the available folders. Each actual cell passes the content/roster/timing/
heading readers and exact evaluator input join before any diagnostic is counted.

Outputs: private `REVIEW_OWNER.json`, `ADMISSION.json`, compact `cells/NNNN.json`,
`INPUT_BINDINGS.json` and `REVIEW.json`, or a preserved `FAILED.json`. Full observed
and scoring results, reference context and compact axes have fingerprints; all
underlying source/reference/application bindings remain in a conflict-checked
registry so detailed results can be reconstructed. Sensitive text and identities
stay private. The compact vectors retain every count with frozen scenario, stage,
pane, reference-support, heading-kind and outcome axes; no category is discarded.
Encoding or population mismatches fail. The axis schema is included in the result.

Grouped results separate composition, panel versus timing-repeat kind, O0/O1 tap
and reference class. Rates are recomputed from **summed counts**, never averages
of per-cell rates. Roster, constant-control identity and reference context must
remain fixed within a composition. Missing/offscreen/suppressed observations,
unresolved support and revision-count availability remain explicit. Empty-caption
virtual spans stay outside lexical denominators. Zero denominators yield null.

The inherited scope remains unchanged: native-span diagnostics based on estimated
reference activity are not exact word or speech-duration naming accuracy. Outside
the available gallery includes missing E members and is not a certified outsider
population. Constant-name/all-Unknown controls hold existing visibility
opportunities fixed; no separate control GUI is rendered. Active/history panes
stay separate, with conflicts counted and no selected winner. Revision sums are
per native span, not independent paint events or continuous wrong-name exposure.
See README_OBSERVED_NAME_SCORING.md and README_NAMING_REFERENCE.md for definitions.

`PASS_COMPLETE_V2_PANEL_NAME_DIAGNOSTICS_ONLY` means the complete planned
diagnostic population was reviewed. It does not establish exact naming/latency,
source callback deadlines, resource tiers, returning-person/fragmentation metrics,
continuity, stop/restart, release qualification or N4 acceptance. Accepted
integrated cells remain zero. The positive production plan/run path still awaits
the actual complete application evidence; synthetic development tests do not
manufacture that evidence.

Resource controls: CPU14, BelowNormal, one math thread, GPU off, model-free helper
lock, one-hour review limit, 8-MiB output cap and campaign disk/private allowance.
Each write is sized before creation. Panels are bounded at 240 cells and input
bindings at 32,768. Count vectors reduce repeated per-cell JSON. A maximum-size
synthetic panel exercises 240 summaries and 96 groups with a separate binding/
admission reserve; actual inputs still must fit the enforced output budget.
Run outside exclusive paced resource measurements. No app, model, waveform,
window, device or Pi is launched by the reviewer.

The development probe checks D1 exact identities/heartbeat/protected bindings
before/after, preserves fresh attempt owners and four source snapshots, and has
a 12-minute limit. Eighteen tests include the eight existing exact population
checks plus saved synthetic reader/scorer compaction, lossless count roundtrips,
hand-computed unequal-denominator aggregation, tap/repeat/reference strata,
scope/binding/axis/count rejection, fixed roster/control integrity, empty metrics
and maximum-panel output sizing. The synthetic reference context is reconstructed
from its qualified inputs. No actual production plan or source run is started.
