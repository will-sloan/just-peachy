Goal:
Implement name assignment for enrolled speakers and conservative Unknown fallback using calibrated similarity thresholds.

Why this matters:
Wrong known-speaker attribution is worse than Unknown. This milestone turns embeddings into product behavior.

Implementation requirements:
- Define SpeakerMatcherBase.match(embedding, enrollment_db) -> SpeakerDecision.
- Define a SpeakerDecision data structure that includes:
  - selected speaker label or Unknown
  - best label before thresholding, if useful
  - confidence/similarity score
  - margin to second-best
  - threshold used
  - threshold decision
  - Unknown fallback reason where applicable
- Implement cosine similarity scoring against speaker centroids and/or multiple exemplars.
- Return the best known speaker only when the configured/calibrated threshold is met.
- Return Unknown conservatively when below threshold.
- Add logic for ambiguous matches using score margin and threshold behavior.
- Handle no enrolled speakers.
- Handle model mismatch or embedding dimensionality mismatch with a clear error or safe Unknown decision, following existing project style.
